# 01. Getting Started

Learn what Link does, install it, and synchronize your first viewports.

## Who this is for

Level designers, environment artists and technical artists who navigate the same space through multiple Level Editor viewports. Link is most useful when one viewport should guide the others while preserving independent viewpoints.

| Topic | What you'll learn | Design | Technical |

| **First Viewport Setup** | Configure a Source, Targets and first linked navigation session. | [Design](first-session/DESIGN.md) | [Technical](first-session/TECHNICAL.md) |

## Key distinction

Link coordinates editor viewport cameras; it does not change your game world.
