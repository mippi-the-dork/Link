# 05. Support and Troubleshooting

Resolve common problems, update Link and provide actionable bug reports.

## How to diagnose a problem

Start with the toolbar and role assignments, confirm at least one relevant axis is enabled, and verify that PIE or camera locks are not preventing updates. Then distinguish continuous linking from one-shot Sync and check whether the target is orthographic.
